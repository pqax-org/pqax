PQAX

Storage views of a footprint: where the bytes of each table go.

Open a file

or drop it here.

The file is read in this browser. Nothing is uploaded, and nothing is kept after the page closes.

    Storage by table

    One bar per table, the most waste first. The live data, then the waste: the files that left the table and may still be stored, the files in the storage that the table does not reference, an estimate of the space of the deleted rows, and the stale columns. After a gap, the overhead of the metadata and the footers, which is not waste. Shares split the live data and the waste of each table, and the overhead goes beyond them.

    Columns by compressed size

    Sources, tables, and columns, sized by compressed bytes and colored by the share of nulls. Click a tile, or press Enter on it, to open it. A hatched tile has no totals in the file.

    File sizes

    The sizes of the data files of each table on a log scale: the line goes from the smallest to the largest file, the box from the first to the third quartile, the mark is the median, and a dot is a file when the footprint keeps the files. The share of V-Ordered files is on the right.

    The views use the packages @pqax/pqax and @pqax/views of pqax-org/pqax. PQAX is a project of SQLBI, released under the MIT license.

The footprint of Parquet and Delta tables. Pronounced "pickax".

PQAX is a file format that holds the storage footprint of the tables of a lakehouse: the files, row groups, and column chunks of each table, with their sizes, and nothing of the data. A .pqax file is a zip of JSON tables, so any zip tool opens it and any language reads it. It can also travel inside a VPAX file, the format of VertiPaq Analyzer, so that a semantic model and the lakehouse it reads are analyzed together.

The format is at version 0.2, a draft that can change until 1.0. The repository pqax-org/pqax holds the documents, the conformance kit, and the reference implementations, under the MIT license.

A first look at a file

pqax info footprint.pqax
pqax check model.vpax

info prints the format version, the collector, the collection level, the parts with the rows of each table, and the totals: tables, columns, files, bytes, rows. check validates a file against every rule of the conformance kit and prints each issue with the code of its rule. Both commands take a .pqax file or a .vpax file that embeds one.

What comes next

The backlog lists the work before 1.0: files from more engines and table formats, the derived measures, and the view model. The storage views at pqax.tools open a .pqax or .vpax file in the browser, without uploading it. Questions and proposals go to the issues of the repository.
